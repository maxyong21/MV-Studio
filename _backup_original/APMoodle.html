Project Overview

APMoodle is a .NET-based Learning Management System (LMS) developed for university students at Asia Pacific University of Technology and Innovation (APU). The platform provides a centralized learning environment where students can access digital learning resources, participate in self-assessment quizzes, and track their academic progress, while lecturers upload teaching materials and administrators manage system content and user data through a secure backend.

Built with ASP.NET Core, Entity Framework Core, and PostgreSQL (hosted on Supabase), the system implements role-based authentication and authorization, form validation, dynamic content management, and responsive navigation to deliver a secure and structured learning experience.

Key Features

Gamified Learning

Quizzes with five selectable themes (Default, Forest, Comic, Watercolor, Kahoot Game Show) and instant results to motivate students

Quiz Feature

Full CRUD quiz system where lecturers create multiple-choice quizzes with correct answer keys, and students attempt and review them

Progress Tracking

Detailed analytics including quiz score trends, average scores, performance breakdown charts, and recent attempt history

Role-based Access

Four distinct user roles — Guests, Students, Lecturers, and Administrators — each with tailored dashboards and permissions

Technical Implementation

The platform is built using ASP.NET Core (.NET 10.0) with Razor Pages for dynamic content generation, Entity Framework Core 9.0 as the ORM, and PostgreSQL via Supabase for cloud-based database hosting. All database interactions are handled through EF Core, eliminating manual SQL writing while supporting version-controlled migrations.

Key technical highlights include two-tier form validation (client-side JavaScript and server-side Data Annotations), a reusable modal system for consistent feedback, soft delete with a "Removed" status to prevent data loss, Google reCAPTCHA v2 integration for password recovery, and a responsive design supporting desktop, tablet, and mobile devices.
